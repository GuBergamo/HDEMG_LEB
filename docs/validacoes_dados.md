# 📊 Validações e Dados Sintéticos

Esta seção mapeia os artigos e bases de dados focados na validação das decomposições e modelagem de sinais[cite: 6].

## Dados Sintéticos e Simuladores

??? info "Bancos de Dados Disponíveis"
    - `Simulated High-Density Surface Electromyographic signals...txt`: Link para diversos `.mat` de EMGs simulados[cite: 6].
    - `Data for MUedit.txt`: Dados do paper de Avrillon (2024)[cite: 6].
    - `Open Access Dataset and Toolbox of HDEMG.txt`[cite: 6].

??? info "Simulador Neuro Motion"
    - **Anotações:** Pacote open-source em Python para simulação de sinais EMG (mão, pulso, antebraço)[cite: 6].
    - **Paper base:** `NeuroMotion Open-source platform.pdf`[cite: 6].

## Artigos de Validação e Modelos

??? success "(LIDO) Tutorial Del Vecchio et al (2020)"
    - **Anotações:** Mostra o passo a passo e precauções durante a decomposição. Não foca em um algoritmo específico[cite: 6].

??? warning "(LER DE NOVO) 25 MUs and diabetes (Valli 2025)"
    - **Anotações:** Usa openhdemg. Conclui que jovens com diabetes tipo 1 sem complicações apresentam alterações no controle neural antes de perda de força[cite: 7].

??? info "(NÃO LIDO) Artigos Diversos de Validação"
    - **Modelos:** Volume condutor cilíndrico de Farina (2004) e Glaser (2017)[cite: 6].
    - **Comparações:** Enoka (2019) compara decomposição com EMG intramuscular[cite: 6]. Nina Murks (2025) avalia edição manual[cite: 7]. Beretta (2019) estima fibras musculares[cite: 6].
